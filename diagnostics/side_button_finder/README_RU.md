# Определение боковой кнопки мыши

Этот временный скетч определяет, какой PS/2-бит выдаёт выбранная боковая кнопка. Рабочий receiver менять не нужно.

## Прошивка

1. Оставьте обе платы соединёнными как в рабочей версии v3.
2. Откройте `side_button_finder.ino` в Arduino IDE.
3. Выберите `Arduino Leonardo` либо совместимый `Pro Micro 5V/16 MHz` и порт главной платы, к которой подключена мышь.
4. Загрузите скетч только в главную плату.
5. Откройте Serial Monitor со скоростью 115200.
6. Если первая строка не появилась, один раз нажмите Reset на главной плате при открытом Serial Monitor.

После успешной инициализации появится строка наподобие:

```text
MOUSE ID: 0x04
```

Нажмите и отпустите только ту боковую кнопку, которую хотите использовать для переключения ноутбуков. Ожидаемый вывод:

```text
SIDE raw=0x10 mask=0x10
SIDE raw=0x00 mask=0x00
```

Для другой боковой кнопки маска обычно равна `0x20`. При одновременном нажатии обеих возможна маска `0x30`.

Пришлите Codex строку `MOUSE ID` и обе строки `SIDE` для нажатия и отпускания. До создания рабочей v4 боковые кнопки ничего не переключают, а средняя кнопка продолжает работать как переключатель.

Если выводится:

```text
SIDE BUTTONS UNAVAILABLE FOR THIS ID
```

пришлите также эту строку: мышь не перешла в PS/2 Explorer-режим, и для боковых кнопок потребуется другой способ чтения.

После проверки можно вернуть рабочую v3 из сохранённого архива `dual-laptop-mouse-switch-working-v3.zip`.
