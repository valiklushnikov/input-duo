# Переключение ноутбуков боковой кнопкой

## Цель

Заменить переключение по средней кнопке на одну выбранную боковую кнопку мыши, сохранив подтверждённую пользователем стабильность рабочей версии v3.

## Этап 1: определение бита

Временный скетч master использует тот же PS/2-транспорт, восстановление после ошибок, USB HID и I2C, что и v3. Дополнительно он открывает Serial на 115200 и после инициализации выводит PS/2 Mouse ID.

Для Mouse ID `0x04` четвёртый байт отчёта содержит колесо в младших четырёх битах и состояния дополнительных кнопок в битах `0x10` и `0x20`. При изменении этих двух битов скетч печатает исходный четвёртый байт и маску боковых кнопок. Повторяющиеся отчёты без изменения не печатаются.

Временный скетч сохраняет переключение средней кнопкой, чтобы обеими системами можно было пользоваться во время определения. Боковые кнопки на этом этапе только регистрируются и ничего не переключают.

Если мышь сообщает ID, отличный от `0x04`, скетч явно выводит, что дополнительные кнопки не представлены в доступном PS/2-отчёте. В таком случае рабочая v4 не создаётся до отдельного исследования режима мыши.

## Этап 2: рабочая v4

После того как пользователь пришлёт строку для нужной кнопки, её маска (`0x10` либо `0x20`) фиксируется константой в master.

- Переключение выполняется только по фронту нажатия выбранной боковой кнопки.
- Удержание кнопки не вызывает повторных переключений.
- Средняя кнопка полностью игнорируется и не передаётся ноутбукам.
- Вторая боковая кнопка также игнорируется.
- Левая и правая кнопки, колесо, движение, I2C-протокол и receiver остаются без изменений.
- При потере PS/2-соединения сохранённое состояние боковой кнопки сбрасывается, чтобы повторное подключение не создало ложный фронт.

## Проверка

Чистая функция извлечения боковых кнопок проверяется для ID `0x04`, значений `0x10`, `0x20`, `0x30`, а также для ID `0x00` и `0x03`, где результат должен быть нулевым. Детектор фронта проверяется для нажатия, удержания и отпускания.

Временный определитель и окончательный master должны полностью компилироваться для Arduino Leonardo/ATmega32U4 5V 16 MHz. Receiver повторно компилируется без изменений. Физический критерий завершения: выбранная боковая кнопка переключает ноутбук один раз, средняя не вызывает действий, движение остаётся плавным на обоих ноутбуках.
